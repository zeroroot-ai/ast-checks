# deadcode allowlist: functions unreachable from the one main that stay on
# purpose (ADR-0094, .github#160). The gate is zeroroot-ai/.github's
# actions/deadcode-gate in CI and `make lint-deadcode` before a push.
#
# This module is a published library with one binary. cmd/unwired imports only
# the unwired package, so deadcode cannot reach the root package from a main and
# reports all of it. Each entry below names the consumer that keeps it, or the
# release that deletes it. The consumers are the gate tests in gibson, setec
# and adk, measured with git grep at origin/main on 2026-10-14. sdk imports no
# package of this module: it runs only cmd/unwired as a go tool.
#
# Keys are the bare symbol deadcode prints after "unreachable func: ", never a
# file or a line, so an unrelated edit never needs a re-pin. Generate an entry
# by running the gate, never by hand. An entry that names nothing FAILS the
# gate, so this file ratchets both ways. Put the reason on a # line above each
# entry.
#
# measured 2026-10-05 with x/tools v0.50.0. The 23 deprecated functions that
# this file carried are deleted (ast-checks#28).
